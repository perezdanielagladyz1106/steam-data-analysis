# Steam-Spieleanalyse mit Excel

Excel-Projekt zur Analyse von Steam-Spielen, erstellt im Rahmen meiner Weiterbildung zur Data Analyst.

## Ziel

Untersuchung von Genres, Preisen und Spielerbewertungen sowie Darstellung der Auswertungen in einem Dashboard.

## Inhalt

Die Arbeitsmappe umfasst drei Tabellenblätter:

- **steam:** Steam-Spieldaten
- **Daten:** unterstützende Auswertungen
- **Dashboard:** visuelle Darstellung der Ergebnisse

Enthalten sind sieben Pivot-Tabellen und zwölf Diagramme.

## Werkzeuge

- Microsoft Excel
- Pivot-Tabellen
- Diagramme und Dashboard

## Projekt öffnen

1. Die Datei **Steam_Games_Analyse.xlsx** im Repository auswählen.
2. Über **Download raw file** herunterladen.
3. In Microsoft Excel öffnen und das Tabellenblatt **Dashboard** auswählen.

Die Arbeitsmappe ist etwa 55 MB groß. Zum Anzeigen des vollständigen Projekts bitte die Datei herunterladen.
